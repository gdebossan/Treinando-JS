# JavaScript Fundamentals

Repositório dedicado à consolidação dos fundamentos de JavaScript por meio de exercícios práticos, desafios de lógica e manipulação de dados.

## Objetivos

- Aprimorar o raciocínio lógico e a resolução de problemas.
- Consolidar conceitos fundamentais de JavaScript.
- Praticar programação funcional e manipulação de dados.
- Desenvolver soluções claras, legíveis e eficientes.
- Trabalhar com operações assíncronas e integração com APIs.

## Tecnologias

- JavaScript (ES6+)
- Node.js
- Git e GitHub

## Como executar

É necessário ter o Node.js instalado.

Clone o repositório:

```bash
git clone https://github.com/gdebossan/javascript-fundamentals.git
cd javascript-fundamentals
```

Execute o exercício desejado:

```bash
node secao-5/exercicios/011-bonus.js
```
