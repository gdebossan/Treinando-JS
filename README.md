## Como executar

É necessário ter o Node.js 22 ou superior. As seções 1 a 5 usam CommonJS,
enquanto a seção 6 usa ES Modules.

Clone o repositório:

```bash
git clone https://github.com/gdebossan/javascript-fundamentals.git
cd javascript-fundamentals
```

Execute o exercício desejado:

```bash
node 05-higher-order-functions/exercises/11-rank-types-by-attack-bonus.js
```
